# yo — mini proyectos

Colección de pequeños proyectos y experimentos de código.

## Estructura

```
yo/
├── python/        # Scripts y proyectos en Python
├── javascript/    # Proyectos en JavaScript / Node.js
├── php/           # Proyectos en PHP
├── web/           # Páginas y experimentos en HTML/CSS
└── otros/         # Otros lenguajes o proyectos mixtos
```

## Cómo usar

Cada carpeta contiene proyectos independientes. Entra a la carpeta del proyecto que te interese y revisa su propio README si tiene uno.

## Lenguajes

- Python
- JavaScript / Node.js
- PHP
- HTML / CSS
